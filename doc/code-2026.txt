1. INTRODUCTION                                         *code-2026-introduction*

code-2026.nvim is a dark and light colorscheme ported from VS Code's
"Dark Modern 2026" theme: red keywords, purple functions, teal types.
Supports dark/light variants with automatic OS color mode detection.

Requires Neovim 0.9+ with 'termguicolors'.

==============================================================================
2. SETUP                                                       *code-2026-setup*

Calling setup() is optional; the defaults apply without it. >lua

    require('code-2026').setup({})
    vim.cmd.colorscheme('code-2026')
<
Calling |code-2026.setup()| while the colorscheme is active reapplies it.

4. BACKGROUND                                             *code-2026-background*

`background` selects the light or dark variant: >
    'dark'     always use the dark palette (default)
    'light'    always use the light palette
    'auto'     detect OS color mode once at setup() and stay fixed
    'sync'     detect at setup() and re-apply on OS color mode changes
<
`'auto'` and `'sync'` read the OS setting via macOS `defaults read -g
AppleInterfaceStyle` or GNOME `gsettings get org.gnome.desktop.interface
color-scheme`. They fall back to `'dark'` when detection is unavailable.

`'sync'` listens for |FocusGained| events and re-applies the theme when the
OS color mode changes.  `vim.o.background` is updated and the `ColorScheme`
event fires so statuslines and other plugins can pick the new palette.

Example: >lua
    require('code-2026').setup({ background = 'sync' })
<
==============================================================================
5. TRANSPARENCY                                         *code-2026-transparency*

`transparent = true` clears the background of Normal, the sign column, line
numbers, the statusline and the tabline.

Floating windows are separate: `styles.floats` is one of >
    'solid'         always painted (default)
    'transparent'   never painted
    'auto'          follows `transparent`
<
==============================================================================
6. STYLES                                                     *code-2026-styles*

Each `styles.<token>` table is merged into the highlight specs for that token.
Add an attribute with `true`, remove a theme default with `false`. >lua

    require('code-2026').setup({
      styles = {
        comments = { italic = false },
        keywords = { italic = true },
        functions = { bold = true },
      },
    })
<
Valid attributes: `bold`, `italic`, `underline`, `undercurl`, `strikethrough`.

==============================================================================
7. PALETTE                                                   *code-2026-palette*

Static overrides: >lua

    require('code-2026').setup({ palette = { bg = '#0d0e0f' } })
<
Programmatic overrides, applied after `palette`: >lua

    require('code-2026').setup({
      on_colors = function(colors)
        colors.bg_float = colors.bg
      end,
    })
<
Derived keys visible to `on_colors`: `bg_normal`, `bg_panel`, `bg_float`,
`bg_inactive`, `err_bg`, `warn_bg`, `info_bg`, `hint_bg` and `terminal`.
All keys are defined in `lua/code-2026/palette.lua`.

==============================================================================
8. HIGHLIGHTS                                             *code-2026-highlights*

>lua
    require('code-2026').setup({
      on_highlights = function(highlights, colors)
        highlights.LineNr = { fg = colors.fg_dim }
      end,
      highlights = {
        Comment = { fg = '#6f7680' },
        Visual = { link = 'CursorLine' },
      },
    })
<
`on_highlights` runs first, then `highlights` is merged on top. Groups merge
per key; a spec containing `link` replaces the group entirely.

==============================================================================
9. PLUGINS                                                   *code-2026-plugins*

Plugin groups are enabled by default and can be disabled by key: >lua

    require('code-2026').setup({ plugins = { telescope = false } })
<
Keys: gitsigns, telescope, fzf_lua, snacks, blink, cmp, bufferline, which_key,
notify, noice, neo_tree, nvim_tree, oil, indent_blankline, mini, lazy, mason,
trouble, flash, illuminate, treesitter_context, rainbow, dap, navic, markdown,
dashboard, yanky, fidget.

lualine users can set `options.theme = 'code-2026'`.

==============================================================================
10. API                                                           *code-2026-api*

code-2026.setup({opts})                                   *code-2026.setup()*
    Stores {opts}. Reapplies the colorscheme if it is already active.

code-2026.load({opts})                                     *code-2026.load()*
    Applies the colorscheme. {opts} override the stored config for this call.

code-2026.colors({opts})                                 *code-2026.colors()*
    Returns the resolved palette table.

code-2026.highlights({opts})                         *code-2026.highlights()*
    Returns the resolved highlight table and palette without applying them.
